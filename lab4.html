Zespół wykładniczych grafów przypadkowych (ERG)

Każdy graf \(G\) o \(N\) węzłach dostaje wagę jak stan w zespole kanonicznym:

\[P(G)=\frac{e^{-H(G)}}{Z},\qquad Z=\sum_{G} e^{-H(G)}\]

Hamiltonian jest kombinacją liniową obserwabli grafu z parametrami \(\theta_i\):

\[H(G)=\sum_{i}\theta_i\,x_i(G)\]
  • \(x_i\) – obserwable: liczba krawędzi \(E\), liczba trójkątów \(T\), gwiazdy…
  • \(\theta_i\) – parametry ustalające średnie \(\langle x_i\rangle\)
  • \(P(G)\) maksymalizuje entropię przy zadanych średnich: nie zakłada nic ponad to, co mierzymy
J. Park, M. E. J. Newman, Statistical mechanics of networks, Phys. Rev. E 70, 066117 (2004)

Graf Erdősa–Rényiego

Zapiszmy hamiltonian za pomocą elementów macierzy sąsiedztwa:

\[H(G)=\theta\sum_{i\lt j}A_{ij}.\]

Wtedy

\[e^{-H(G)}=e^{-\theta\sum_{i\lt j}A_{ij}}=\prod_{i\lt j}e^{-\theta A_{ij}}.\]

Sumowanie po wszystkich grafach oznacza niezależne sumowanie po wszystkich możliwych wartościach \(A_{ij}\):

\[Z=\sum_{A_{12}=0}^{1}\sum_{A_{13}=0}^{1}\cdots\sum_{A_{N-1,N}=0}^{1}\prod_{i\lt j}e^{-\theta A_{ij}}.\]

Ponieważ każdy czynnik zależy tylko od jednej zmiennej \(A_{ij}\), możemy zamienić sumowanie na iloczyn:

\[Z=\prod_{i\lt j}\left(\sum_{A_{ij}=0}^{1}e^{-\theta A_{ij}}\right)=\prod_{i\lt j}\left(e^{0}+e^{-\theta}\right)=\prod_{i\lt j}\left(1+e^{-\theta}\right)\]
Ze wzoru
\[\langle E\rangle=p\binom{N}{2}=-\frac{\partial\ln Z}{\partial\theta}\]
dostaniemy związek
\[p=\frac{1}{1+e^{\theta}}.\]
J. Park, M. E. J. Newman, Statistical mechanics of networks, Phys. Rev. E 70, 066117 (2004)

Algorytm Metropolisa na grafach

Błądzimy po przestrzeni grafów, zmieniając jedną parę węzłów naraz:

  1. Wylosuj parę węzłów \((i,j)\)
  2. Zaproponuj przełączenie: \(A_{ij}\to 1-A_{ij}\)
  3. Policz zmianę energii \(\Delta H\)
  4. Zaakceptuj z prawdopodobieństwem \(P_{\mathrm{acc}}=\min(1,e^{-\Delta H})\)
  5. Zapisz obserwable i wróć do 1.
\[\begin{aligned}\Delta H&=H(G^{\prime})-H(G)=\theta\sum_{k\lt l}A^{\prime}_{kl}-\theta\sum_{k\lt l}A_{kl}\\&=\theta\sum_{k\lt l}\left(A^{\prime}_{kl}-A_{kl}\right)=\theta\left(A^{\prime}_{ij}-A_{ij}\right)=\theta\left(1-2A_{ij}\right)\end{aligned}\]
N. Metropolis et al., Equation of state calculations by fast computing machines, J. Chem. Phys. 21, 1087 (1953)

Kod 1: symulacja grafu wykładniczego

import matplotlib.pyplot as plt
import numpy as np

N = 100
theta = 1
steps = 100_000
A = np.zeros((N, N), dtype=int)
E = 0
history_E = []

# Graf wykładniczy H = theta*E - Metropolis
for _ in range(steps):
  i, j = np.random.choice(N, 2, replace=False)
  dH = theta * (1 - 2 * A[i, j])

  if dH < 0 or np.random.rand() < np.exp(-dH):
    new_val = 1 - A[i, j]
    A[i, j] = A[j, i] = new_val
    E += 2*new_val - 1

  history_E.append(E)

# Wykres E(t)
p = 1 / (1 + np.exp(theta))
plt.plot(history_E)
plt.axhline(N * (N - 1) * p / 2, color='red', ls='--')
plt.xlabel('t')
plt.ylabel('E(t)')
plt.show()
  • \(\Delta H\) jednego przełączenia: dH = …
  • akceptacja: \(\min(1,e^{-\Delta H})\)
  • bieżąca liczba krawędzi: E += …
  • \(p=1/(1+e^{\theta})\)
  • teoria: \(\langle E\rangle=p\binom{N}{2}\) (linia przerywana)

Zadanie 1: klasyczny graf ER o tej samej gęstości

Zbuduj klasyczny graf ER o \(N=100\) węzłach, łącząc każdą parę z prawdopodobieństwem \(p=1/(1+e^{\theta})\).

# Klasyczny model ER
p = 1 / (1 + np.exp(theta))
B = np.zeros((N, N))
for i in range(N):
  for j in range(i + 1, N):
    if np.random.rand() < p:
      B[i, j] = 1
      B[j, i] = 1

Policz stopnie węzłów w obu grafach i porównaj histogramy.

# Rozkłady stopni obu sieci

Nagroda za trójkąty: model Straussa

Do liczby krawędzi dodajemy liczbę trójkątów \(T\) z wagą \(\alpha\gt 0\):

\[H=\theta E-\alpha T\]
  • Przełączenie pary \((i,j)\) zmienia \(T\) o liczbę wspólnych sąsiadów: \(c_{ij}=\sum_k A_{ik}A_{kj}\) (w kodzie: A[i] @ A[j])
\[\Delta H=\theta\,\Delta E-\alpha\,\Delta T=\left(\theta-\alpha c_{ij}\right)\Delta E\]
  • Krawędzie domykające trójkąty są tańsze: sieć się klasteryzuje

dodanie krawędzi \(i-j\) tworzy \(c_{ij}=2\) trójkąty

D. Strauss, On a general class of models for interaction, SIAM Review 28, 513 (1986)

Zadanie 3: Wyznaczyć energię swobodną w przybliżeniu pola średniego

Energia swobodna Helmholtza jest zdefiniowana jako

\[F=U-TS.\]

Przyjmujemy \(k_BT=1\), dlatego w bezwymiarowych jednostkach

\[F(p)=U(p)-S(p).\]

Krok 1. Liczymy energię \(\boldsymbol{U(p)}\)

Zakładamy, że każda z możliwych krawędzi istnieje niezależnie z takim samym prawdopodobieństwem \(p\).

Jest to przybliżenie pola średniego, ponieważ w rzeczywistym modelu Straussa krawędzie nie są niezależne.

Średnia liczba krawędzi

\[\langle E\rangle=\binom{N}{2}p\]

Średnia liczba trójkątów

\[\langle T\rangle=\binom{N}{3}p^{3}\]

Średnia energia

\[U(p)=\langle H\rangle=\theta\langle E\rangle-\alpha\langle T\rangle=\theta\binom{N}{2}p-\alpha\binom{N}{3}p^{3}\]
J. Park, M. E. J. Newman, Solution for the properties of a clustered network, Phys. Rev. E 72, 026136 (2005)
10

Krok 2. Liczymy entropię \(\boldsymbol{S(p)}\)

\[S=\ln\Omega\qquad(\text{bo }k_B=1)\]

gdzie \(\Omega\) jest liczbą mikrostanów odpowiadających danemu makrostanowi.

Mikrostan to konkretny graf, makrostan opisujemy liczbą krawędzi \(E\) (lub gęstością \(p\)).

Liczba grafów o zadanej liczbie krawędzi

\[\Omega(E)=\binom{\binom{N}{2}}{E}\]

← górny wyraz: ze wszystkich możliwych krawędzi

← dolny wyraz: wybieramy \(E\) krawędzi

Po zastosowaniu przybliżenia Stirlinga i pamiętając, że \(E=\binom{N}{2}p\)

\[S(p)=-\binom{N}{2}\left[p\ln p+(1-p)\ln(1-p)\right]\]
J. Park, M. E. J. Newman, Solution for the properties of a clustered network, Phys. Rev. E 72, 026136 (2005)
11
\[F(p)=U(p)-S(p)\]

Otrzymujemy ostatecznie

\[\begin{aligned}F(p)=&\;\theta\binom{N}{2}p-\alpha\binom{N}{3}p^{3}\\&+\binom{N}{2}\left[p\ln p+(1-p)\ln(1-p)\right]\end{aligned}\]

Jeśli ustalimy \(\alpha\) i \(N\), to dostaniemy

J. Park, M. E. J. Newman, Solution for the properties of a clustered network, Phys. Rev. E 72, 026136 (2005)

Zadanie 4: badanie metastabilności

N = 20
alpha = 0.5
steps = 1000

A = np.zeros((N, N), dtype=int)
E = 0
T = 0

# Zwiększamy, a następnie zmniejszamy theta
thetas = np.linspace(0, 10, 20)
thetas = np.r_[thetas, thetas[::-1]]

history_E = []
history_T = []

for theta in thetas:

    for _ in range(steps):
        i, j = np.random.choice(N, 2, replace=False)

        c = A[i] @ A[j]
        dE = 1 - 2*A[i, j]
        dH = (theta - alpha*c) * dE

        if dH < 0 or np.random.rand() < np.exp(-dH):
            A[i, j] = A[j, i] = 1 - A[i, j]
            E += dE
            T += dE*c

    history_E.append(E)
    history_T.append(T)
  • thetas: \(\theta\) w górę, potem w dół
  • history_E, history_T: stan po steps krokach
